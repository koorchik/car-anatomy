# Переклад

Сайт двомовний: українська і англійська. Українська є джерелом, а англійський текст лежить у `src/i18n/en/`.

Мова вибирається один раз під час завантаження (`src/i18n/locale.ts`): адреса `?lang=`, потім збережений вибір, потім мова браузера. Перемикання перезавантажує сторінку, тому текст можна будувати й на рівні модуля.

- Текст інтерфейсу: `t('Український текст')` або `t('Запалювання відкочено на {deg}°', { deg })`. Перший аргумент завжди рядковий літерал, без склейки. Переклад додається в `en/ui.ts` або `en/designer.ts`.
- Числа: `toLocaleString(numberLocale)`, не `'uk-UA'`.
- Каталог: `en/engines.ts` за id сторінки, `en/variants.ts` за `сторінка/двигун`.
- `tests/i18n.test.ts` не пропустить кирилицю поза `t()`, рядок без перекладу чи різні заповнювачі в двох мовах.
