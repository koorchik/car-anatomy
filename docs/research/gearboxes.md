# Коробки передач і трансмісія: дослідження

Зведення трьох дослідницьких звітів (механіка, реальні дані, симуляція з 3D і звуком) і перевірок, зроблених під час планування 12–13 листопада 2026 року, з доповненнями після незалежної критики плану (13 листопада). Це довідка для плану `docs/superpowers/plans/2026-11-12-gearboxes.md`, а не текст для сайту. Числа, які підуть у каталог, мають позначку доказовості. Без першоджерела вони потрапляють на сайт лише з `verifyNote` або в списку `unverified`.

## Позначки

- **[П]** прочитано в першоджерелі: документ виробника, звіт лабораторії, наукова стаття, патент, закон.
- **[В]** прочитано у вторинному джерелі: Вікіпедія, фахова преса, сайти ентузіастів.
- **[О]** обчислено скриптом із даних [П] або [В]. Якщо написано «відтворює», скрипт дав рівно опубліковані числа.
- **[Т]** стандартна формула з підручника або власний інженерний висновок.
- **[Н]** не перевірено: з пам'яті або лише з анотації пошукової системи. Перед використанням у даних звірити.

Скрипти перевірки лежать поза репозиторієм у локальних теках попереднього запуску: розв'язувач 8HP (`zf8hp.py`), власні частоти трансмісії (`modes.py`), стійкість інтеграторів і закон блокування (`integ.py`), фази зачеплення (`mesh.py`, `planets.py`). Їхні результати нижче повторено числами, тож самі скрипти для плану не потрібні.

## 1. Загальні співвідношення [Т]

| Величина | Співвідношення |
|---|---|
| Передаточне число | `i = ω_вх/ω_вих`, `T_вих = i·η·T_вх` |
| Швидкість авто | `v = ω_дв·r_дин/(i_п·i_гп)` |
| Тягове зусилля | `F = T_дв·i_п·i_гп·η/r_дин` |
| Діапазон і крок | `φ = i_1/i_n`, `φ_k = i_k/i_{k+1}` |
| Приведена інерція | `J_екв = J_колеса + i_гп²·J_кардана + (i_п·i_гп)²·(J_дв + J_зчеплення + J_вх)` |
| ККД планетарного ряду | Вікіпедія для 8HP і 6HP бере `η₀ = 0,97–0,98` на ряд (два зачеплення), тобто 0,985–0,99 на зачеплення [В] https://en.wikipedia.org/wiki/ZF_8HP_transmission |

ККД за передачами з таблиць Вікіпедії (8HP перша ≈0,947 або 0,921) розраховано з припущеного `η₀`, а не виміряно [В]. Цитувати їх як вимір не можна.

## 2. Геометрія зубців

### 2.1 Евольвента [Т], форма ISO 21771

| Що | Формула |
|---|---|
| Торцевий модуль, ділильний діаметр | `m_t = m_n/cos β`, `d = m_n·z/cos β` |
| Торцевий кут профілю | `tan α_t = tan α_n/cos β` |
| Основне коло, основний крок | `d_b = d·cos α_t`, `p_bt = π·m_t·cos α_t` |
| Вершини й западини | `d_a = d + 2m_n(1 + x)`, `d_f = d − 2m_n(1,25 − x)` |
| Міжосьова без зміщення | `a = m_n(z₁ + z₂)/(2 cos β)` |
| Зі зміщенням | `inv α_wt = inv α_t + 2 tan α_n·(x₁ + x₂)/(z₁ + z₂)`, `a_w = a·cos α_t/cos α_wt`, `inv α = tan α − α` |
| Торцевий коефіцієнт перекриття | `ε_α = [√(r_a1² − r_b1²) + √(r_a2² − r_b2²) − a_w sin α_wt]/p_bt` |
| Осьовий коефіцієнт перекриття | `ε_β = b·sin β/(π·m_n)` |
| Сумарний | `ε_γ = ε_α + ε_β` [П] https://www.mahle-powertrain.com/transmissions/en/encyclopedia/contactratio.jsp |
| Підрізання | `z_min = 2/sin²α ≈ 17` при 20°; додатне зміщення `x` його прибирає |
| Осьова сила косозубої пари | `F_a = F_t·tan β` |
| Напрям зубців | зовнішня пара має протилежні напрями, внутрішня (сателіт і коронна) однакові |
| Частота зачеплення | `f = z·n/60`; порядок завивання дорівнює числу зубців |

Точка евольвенти при куті розгортання `t`: `(r_b(cos t + t sin t), r_b(sin t − t cos t))`, нормаль `(sin t, −cos t)` дотична до основного кола. Півкут зубця на радіусі `r`: `ψ(r) = (π/2 + 2x tan α)/z + inv α − inv α_r − j/(2r_p)`, де `j` бічний зазор на ділильному колі [Т].

### 2.2 Фаза зачеплення [О], перевірено числово

- **Зовнішня пара.** Центр шестерні B лежить у напрямку `φ` від A, `θ` означає кут центру зубця 0: `θ_B = φ + π + π/z_B − (z_A/z_B)(θ_A − φ)`.
- **Внутрішня пара** (сателіт усередині коронної в напрямку `ψ`): `θ_R = ψ + π/z_R + (z_P/z_R)(θ_P − ψ)`. З рухомим водилом усі кути беруться в системі водила.
- **Перевірка.** У 12 положеннях пари 19/43, 20/20, 17/31, 29/38 і внутрішні 23/78, 24/72, 18/60 не мають жодного перетину. Помилка на пів кроку дає 20–75 тис. точок перетину.
- **Сателіти.** Фазу кожного сателіта беремо із зачеплення з сонячною, а фазу коронної з сателіта 0. Тоді всі сателіти не перетинаються з коронною, якщо `(z_s + z_r)/N` ціле: S48/R96 при N = 3 і 4, S28/R104 при N = 4, S30/R78 при N = 4. S30/R78 з N = 5 (неціле) дає 14,7 тис. перетинів.
- **Нестандартні зубці.** Prius має сонячну 30, сателіти 23, коронну 78. `30 + 2·23 = 76 ≠ 78`, тож колеса зі зміщенням профілю [О з [П]]. Кількість сателітів не можна виводити з `(z_r − z_s)/2`.

### 2.3 Кут, точність, накопичення [Т]

- Кут кожної шестерні виводимо з кута її вала через передаточні числа, а не інтегруємо окремо. Інакше зубці розходяться.
- Перескок кута ведучої на 2π зсуває ведену на ціле число кроків, і для зубців цього не видно. Для міток, спиць і написів, кількість яких не ділить `z`, видно, тож їх ведемо за незгорнутим кутом.
- Кути тримаємо в float64 на процесорі, у шейдер передаємо вже згорнутий кут.

### 2.5 Допустимі напруження

Таблиць ISO 6336-5 для цементованої сталі (`σ_Flim`, `σ_Hlim` для класу MQ) прочитати не вдалося: стандарт платний, а у вільних фрагментах значень немає [Н] https://webstore.ansi.org/preview-pages/ISO/preview_ISO+6336-5-2016.pdf. Тому модель міцності в конструкторі калібрується однією глобальною сталою на одній відомій парі (див. план), а число 700 МПа з TTAC лише перевіряє порядок.

**Розрахунок пари 1-ї TR-6060 MZ6 [О]** (формули плану: `F_t = T_вх·i_г·(1 + u)/a`, `σ_F = F_t/(b·m_n)·Y_FS·Y_β`):

| Величина | Значення |
|---|---|
| Номінал MZ6 | 580 Н·м (GM: «validated to 428 lb-ft» [В]) |
| Момент на проміжному валу | `580·38/29 = 760 Н·м` |
| `d₁ = 2a/(1 + u)`, `u = 43/19` | 52,1 мм |
| `F_t` | 29,2 кН |
| `m_n` при `a = 85`, `β = 25°` | 2,49 мм |
| `ε_β = b·sin β/(π m_n)` при `b = 30` | 1,62, тож `Y_β` упирається в нижню межу 0,75 |
| `z_n = z/cos³β`, `Y_FS ≈ 3,47 + 13,2/z_n` | 25,5 і 3,99 |
| `σ_F` на номіналі | близько 1170 МПа |
| `σ_F` на 600 lb-ft (сценарій TTAC) | близько 1640 МПа |

- Наша номінальна формула дає на 600 lb-ft приблизно в 2,3 раза більше, ніж FEA TTAC (700 МПа). Тому 700 МПа не можна брати як абсолютну межу для цієї формули, лише як порядок.
- 1170 МПа на номіналі — межа обмеженого ресурсу цементованої сталі: `σ_FE = 2σ_Flim` близько 1000 МПа для якісної сталі [Т/Н] і множник ресурсу понад 1 на 10⁴–10⁵ циклів [Т]. Звідси правило плану: навантаження 1,0 на номіналі цієї пари задає одну глобальну сталу.
- Набори A–F мають невідомі зубці. Добуток «номінал × перше число» A 1746, решта 1989–2155 Н·м: A на 13% нижчий, тож «сталий вихід» лише наближений і як закон моделі не годиться.

## 3. Механічні коробки

### 3.1 Схеми [Т, де не сказано інше]

- **Двовальна поперечна (передній привід).** Первинний і вторинний вали, кожна передача проходить одне зачеплення, `i_k = z_вих/z_вх`, шестерня вторинного вала крутить ведене колесо головної передачі. Прямої передачі немає. Щоб скоротити картер, передачі розносять на два вторинні вали з різними шестернями головної передачі, як у VW DQ250 [П, SSP 308].
- **Тривальна з проміжним валом (задній привід).** Первинний і вторинний вали співвісні. Головна пара постійно крутить проміжний вал. Непряма передача йде через два зачеплення: `i_k = (z_пв/z_вх)·(z_k,вих/z_k,пв)`. Пряма передача з'єднує первинний вал із вторинним без зачеплень, тому вона найефективніша.
- **Постійне зачеплення.** Усі шестерні передач увесь час у зачепленні. Шестерні на одному валу крутяться вільно на голчастих підшипниках, а вал з'єднує з ними ковзна муфта через вінець включення [В] https://en.wikipedia.org/wiki/Manual_transmission. Це головне, що має показати 3D: усі шестерні крутяться завжди, вільна шестерня на валу крутиться зі своєю швидкістю.
- **Задній хід.** Класично прямозуба ковзна проміжна шестерня вводиться між двома шестернями заднього ходу без синхронізатора, тому вмикати його можна лише на місці, і він завиває [В]. Багато сучасних коробок мають синхронізатор і на задньому ході. DQ250 має двоконусний синхронізатор заднього ходу й окремий вал заднього ходу [П, SSP 308].
- **Механізм перемикання.** Куліса, штоки, вилки, муфти, фіксатори й замок, що не дає ввімкнути два штоки одночасно.
- **Історія.** Перший синхронізатор стояв на Cadillac 1929 року [В].

## 4. Синхронізатор

### 4.1 Деталі й фази

- Маточина на шліцах вала, муфта, блокувальне кільце з конусом і блокувальними фасками, конус шестерні з вінцем включення, сухарі з пружинами, що штовхають кільце поперед муфти. Багатоконусні мають проміжне і внутрішнє кільця.
- DQ250: триконусні на 1–3, бо «перепад швидкостей на нижчих передачах більший», одноконусні на 4–6, двоконусний на задньому; кільця латунні з молібденовим покриттям [П] SSP 308, https://www.vaglinks.com/Docs/SSP/VWUSA.COM_SSP_851403_DSG.pdf.
- Фази для анімації (стисло з дисертації Chalmers, у Lovas і Liu–Tseng до 11 фаз) [П] https://publications.lib.chalmers.se/records/fulltext/245949/245949.pdf, https://opus.lib.uts.edu.au/bitstream/10453/18350/1/2011001239.pdf:
  1. **Переддотик.** Муфта сходить із фіксатора, сухарі притискають кільце до конуса, олива витискається, в'язке тертя повертає кільце на пів кроку в блокувальне положення.
  2. **Синхронізація.** Фаски муфти тиснуть на фаски кільця, муфта стоїть. Конус ковзає, `Δω` падає. Поки момент конуса більший за момент розблокування, кільце тримає муфту.
  3. **Розблокування.** Коли `Δω → 0`, момент конуса зникає, фаски провертають кільце й шестерню назад на частку кроку, муфта проходить крізь зубці кільця.
  4. **Включення.** Зубці муфти зустрічають фаски вінця, вирівнюються й заходять. Залишковий `Δω` від опору оливи дає «другий поштовх» або часткове зіткнення [П] UTS.

### 4.2 Рівняння

- Момент конуса: `T_C = μ_C·F_a·R_C/sin α` [П] UTS, рівняння 4. Для `n` конусів `T_C ≈ F_a·Σ(μ_i R_i)/sin α` [Т].
- Момент на фасках: `T_I = F_a·R_I·(1 − μ_I tan γ)/(μ_I + tan γ)`, де `γ` кут фаски від осі (половина кута даху) [П] UTS, рівняння 5; незалежно виведено [О].
- **Умова блокування:** `μ_C·R_C/sin α ≥ R_I·(1 − μ_I tan γ)/(μ_I + tan γ)`. Сила `F_a` скорочується: натиснувши сильніше, кільце раніше не розблокуєш. Приклад [О]: `μ_C 0,10`, `R_C 35 мм`, `α 6,5°`, `R_I 40 мм` дає ліву частину 0,773·R_I. Права при `μ_I = 0,06` дорівнює 0,74·R_I при `γ = 50°` (на межі) і 0,50·R_I при `γ = 60°` (з запасом).
- Самогальмування: якщо `α` замалий (`μ_C > tan α`), кільце прилипає до конуса [П] UTS.
- Швидкості під час синхронізації: `I·ω̇ = T_C ± T_D`; синхронізація не вдається, якщо `T_D > T_C` [П] UTS, рівняння 9–10.
- **Час синхронізації** для синхронізатора на вторинному валу, у величинах первинного [О]: `Δω_вх = ω_вих(i_старе − i_нове)`. Вгору `t = J_вх·Δω_вх·i_k/(T_C + i_k T_оп)`, опір допомагає. Вниз `t = J_вх·Δω_вх·i_k/(T_C − i_k T_оп)`, опір заважає. `J_вх` включає диск зчеплення, первинний і проміжний вали та шестерні в зачепленні з ними.
- **Приклад [О]:** 2→3 на 6000 об/хв, `i₂ 2,05`, `i₃ 1,30`, `J_вх 0,010 кг·м²`, `F_a 600 Н`, опір 1 Н·м. `Δω_вх = 230 рад/с`, одноконусний `T_C = 18,6 Н·м`, `t ≈ 0,15 с`; триконусний (близько 2,6 раза більший момент) `t ≈ 0,06 с`. Робота тертя `½J·Δω² = 265 Дж`, пікова потужність 4,3 кВт. На конусі 35 × 8 мм (1760 мм², оцінка) це 0,15 Дж/мм² і 2,4 Вт/мм². Патентні точки випробувань 0,46–2,46 Дж/мм² і 0,96–2,67 Вт/мм² того самого порядку [Н]. *Поправка етапу K2a [О]:* 4,3 кВт — це `T_C·Δω_вх`, а конус ковзає між вільною шестернею (`ω_вх/i`) і маточиною, тобто на `Δω_вх/i₃ = 177 рад/с` на початку. Пікова потужність на конусі `T_C·Δω_вх/i₃ = 3,3 кВт`, на площу 1,9 Вт/мм². Це `2E/t` без опору (265 Дж за 0,161 с); з опором 1 Н·м час 0,15 с, а робота на конусі 247 Дж. Енергія без опору та сама.
- **Хрускіт [О/Т].** Якщо муфту продавлено крізь кільце до `Δω ≈ 0`, її зубці перескакують зубці вінця з частотою `f = z_вінця·Δω/2π`: 36 зубців × 100 рад/с ≈ 570 Гц, тон падає разом із `Δω`.

## 6. Зчеплення й двомасовий маховик

- **Ємність:** `T_max = μ·z·F_N·r_m`, `z` кількість поверхонь тертя (2 для одного сухого диска, 4 для двох). Середній радіус за рівномірного зносу `(r_з + r_в)/2`, за рівномірного тиску `⅔(r_з³ − r_в³)/(r_з² − r_в²)` [Т]. Запас `T_max/T_дв ≈ 1,2–1,5` [Т].
- **Тертя накладок.** Органічна накладка: близько 0,25 при кімнатній температурі, до 0,37 близько 260 °C, далі різко падає [Н, анотація патенту US 4951793 https://image-ppubs.uspto.gov/dirsearch-public/print/downloadPdf/4951793]. Мокрий пакет в ATF 0,10–0,15 [Н]. Тертя падає з температурою і швидкістю ковзання [В, огляд] https://www.mdpi.com/2073-4360/14/9/1757.
- **Діафрагмова пружина** має спадну характеристику Бельвіля, тому зусилля притискання майже не змінюється зі зносом накладок [Т].
- **Модель тертя для симуляції** (KAIST, рівняння 6–7, після Crowther і Zhang) [П] https://acl.kaist.ac.kr/wp-content/uploads/2021/10/2017_MMT_KSY.pdf: розімкнене — 0; ковзає — `μ_k F_n r_c N D sgn(Δω)`; зчеплене — момент, що тримає зчеплення, поки `μ_s F_n r_c N D` не менший за нього.
- **Двомасовий маховик** [В] https://en.wikipedia.org/wiki/Dual-mass_flywheel: первинна маса на колінвалі, вторинна з зчепленням, між ними дугові пружини (одна, дві паралельні, де внутрішня коротша й вмикається пізніше, або три ступені). Знос видно як вільний хід і хитання. Модель `T_d = k_d(θ_e − θ_d) + b_d(ω_e − ω_d)`. Резонанс `f = (1/2π)√(k(J₁ + J₂)/(J₁J₂))` ставлять значно нижче частоти спалахів на холостому [Т]. Mercedes 9G-Tronic додає до демпфера відцентровий маятниковий гасник [В].
- **LuK про двомасовий маховик** [П] Albers, LuK Symposium 1994, https://www.schaeffler.com/remotemedien/media/_shared_media/08_media_library/01_publications/schaeffler_2/symposia_1/downloads_11/1_Dual_Mass_Flywheel_1.pdf:
  - мода 1 (ривки при натисканні й скиданні газу) 2–10 Гц;
  - мода 2 з демпфером у диску 40–80 Гц, це «типова причина деренчання»;
  - мода 2 з двомасовим маховиком 7,5–15 Гц, нижче частоти спалахів холостого, тому ізоляція працює від холостого вгору;
  - чотиримасова уточнена модель: 4–8, 6–15 і 80–120 Гц;
  - з диском резонанс із тертям біля 1700 об/хв; двомасовий маховик розраховано на ізоляцію вище 700 об/хв, резонанс проходять лише при пуску й зупинці;
  - внутрішній демпфер підняв ізоляцію нерівномірності з 93 до 95%;
  - «навіть у дизеля кут коливань рідко більший за ±2°»; збудження деренчання — гармоніки спалахів 20–400 Гц.

- **Фізика передачі моменту між зчепленнями** (KAIST, рівняння 1–9) [П]: `J_e ω̇_e = T_e − T_c1 − T_c2`; `J_cti ω̇_ci = T_ci − T_ti/i_ti`; `J_o ω̇_o = i_f1 T_t1 + i_f2 T_t2 − T_o`.
  - **Фаза моменту:** наступна передача вже ввімкнена, нове зчеплення бере момент, старе віддає. Оберти ще прив'язані до старої передачі, тож момент на виході падає від `i_старе·T_e` до `i_нове·T_e`. Старе має відпустити рівно тоді, коли його момент перетинає нуль: раніше — оберти злітають, пізніше — зчеплення борються.
  - **Інерційна фаза:** нове зчеплення ковзає і тягне двигун до нових обертів: `T_c,нове = T_e − J_e ω̇_e`. Момент на виході вищий за `i_нове·T_e` на інерційну частку, якщо не прибрати момент двигуна. KAIST прибирає його лише в цій фазі.
  - **Вниз** навпаки: спершу двигун піднімають (старе ковзає або підгазовка), потім передають момент.
  - **Обмеження для будь-якого регулятора:** моменти зчеплень не від'ємні, швидкості їх зміни не змінюють знак, моменти не вищі за ємність, темп обмежений приводом, двигун не глухне.
- **Симуляція KAIST 1→2** [П, таблиця 2]: «комфорт» 1,80 м/с², ривок 13,1 м/с³, провал 96 Н·м, 0,69 с, 2,22 кДж; «швидко» 2,74 м/с², 21,7 м/с³, 96 Н·м, 0,48 с, 1,74 кДж. Провал задає фаза моменту, налаштування міняє лише ривок, час і тепло інерційної фази.

## 10. Планетарні автомати

### 10.1 Рівняння

- **Простий ряд:** `z_s·ω_s + z_r·ω_r = (z_s + z_r)·ω_c` [В] https://en.wikipedia.org/wiki/Epicyclic_gearing; `i₀ = −z_r/z_s`.
- **Двосателітний ряд:** `z_s ω_s − z_r ω_r = (z_s − z_r) ω_c`, `i₀ = +z_r/z_s` [Т].
- **Обертання сателіта відносно водила:** `ω_p − ω_c = −(z_s/z_p)(ω_s − ω_c)` [Т].
- **Ідеальні моменти:** `T_s : T_r : T_c = z_s : z_r : −(z_s + z_r)` [Т].
- **Аналогія важеля** (Benford і Leising, SAE 810102): кожен ряд — вертикальний важіль, точки S, C, R на відстанях, пропорційних `z_r` і `z_s`, швидкості лежать на прямій [Т]. Сторінка 9G-Tronic у Вікіпедії використовує саме такі номограми [В].

Приклад: двигун 2000 об/хв, коронна 3000 об/хв дають MG1 −600 об/хв, тобто він крутиться назад і працює двигуном (рециркуляція потужності). Заднього ходу немає, MG2 просто крутиться назад. «Нейтраль» означає нуль моменту на моторах. Режим EV: двигун стоїть, MG1 крутиться вільно.
- Покоління 4 (P610) [В] https://en.wikipedia.org/wiki/Hybrid_Synergy_Drive: паралельні вали замість редукторного ряду, на 20% менші механічні втрати, MG2 53 кВт / 163 Н·м.

## 13. Головна передача й диференціали

- **Головна передача [Т]:** у поперечних коробках косозуба циліндрична пара, у поздовжніх задньоприводних гіпоїдна; зміщення шестерні гіпоїда додає ковзання, ККД нижчий, потрібна EP-олива; 2,5–4,5.
- **Вільний диференціал:** `ω_корпусу = (ω_л + ω_п)/2`, `T_л = T_п = T_к/2` мінус тертя. Колесо з меншим зчепленням задає момент обох; колесо в повітрі крутиться на `2ω_к`, авто стоїть. Сумарний момент близько двох моментів слабшого колеса [П] Chocholek, IMechE C368/88, https://flashoffroad.com/features/Torsen/Torsen_white_paper.pdf.
- **Одне колесо на льоду — авто не стоїть [О].** Момент льоду отримують обидва колеса, тож сила `2·F_льоду`. ВАЗ-2101 (1030 кг з водієм, 47% на задній осі [оцінка], μ льоду 0,1, `C_rr` 0,012): `F_льоду` близько 237 Н, `2F` близько 475 Н, кочення близько 121 Н, прискорення близько 0,34 м/с². Авто повзе. Не може піднятися, коли `m·g·sin θ > 2F − F_кочення`, тобто з ухилу близько 3,5%. Ліве колесо крутиться на `2ω_к − ω_п`, а не «вдвічі швидше за корпус», доки праве котиться.
- **Повний привід, передня вісь на льоду [О].** Вільний міжосьовий із розподілом `s_п : s_з` дає задній осі `F_п·s_з/s_п`. WRX STI (1615 кг з водієм, 60% спереду [оцінка], DCCD 41/59): спереду близько 951 Н, ззаду 1368 Н, разом близько 2,3 кН, прискорення близько 1,3 м/с². На підйомі передня вісь розвантажується, межа близько 12–13%. Блокування міжосьового вмикає задню вісь з її повним зчепленням.
- **Діагональне вивішування [Т].** Переднє ліве й заднє праве в повітрі: обидва вільні мостові дають нуль, тож блокування міжосьового нічого не дає. Потрібні самоблоки з попереднім стисненням, блокування мостових або гальмування колеса електронікою.
- **Карданний шарнір [Т].** `ω₂/ω₁ = cos β/(1 − sin²β·cos²θ)`, де `θ` — кут вхідної вилки від площини валів. Діапазон від `cos β` до `1/cos β`, двічі за оберт, середнє 1. Два шарніри з рівними кутами й вилками проміжного вала в одній площині дають рівномірний вихід; зсув вилок на 90° подвоює нерівномірність. На 3° розмах близько ±0,14%, на 30° від 0,866 до 1,155. ШРУС тримає кульки в бісекторній площині, і швидкість стала на будь-якому куті.
- **Самоблок із пакетами і рампами** [В] https://en.wikipedia.org/wiki/Limited-slip_differential: вісі сателітів лежать у V-подібних рампах двох натискних кілець; момент змушує їх підійматися й стискати пакети. Симетричні рампи — двобічний, пилкоподібні — однобічний (вільний на скиданні), різні кути — півторабічний. Рампа 30° дає найбільше притискання, 90° найменше, типово близько 45°; на скиданні 80–85° [П] патент https://image-ppubs.uspto.gov/dirsearch-public/print/downloadPdf/6283889.
  - Виведення [О/Т]: `F_a = T_к/(r_р tan θ)`, `T_f = μ n r_m (F_пер + F_a)`; без попереднього стиснення `T_f = k·T_к`, `k = μ n r_m/(r_р tan θ)`, **TBR = (1 + k)/(1 − k)**; `T_більше,менше = (T_к ± T_f)/2`. Попереднє стиснення дає сталий момент блокування навіть без тяги, заважає на парковці й ABS [П] Chocholek.
- **Torsen** [П] https://torsen.com/how-it-works/: TBR — «відношення більшого зчеплення до меншого, яке диференціал дозволяє, лишаючись заблокованим»; зміщення моменту від осьових сил косих зубців, тертя пропорційне моменту. T-1 2,5–6:1 (Hummer близько 4,5:1) [П Chocholek; В]; T-2 2–2,5:1; T-2R 3–4:1 [В]. `TBR × 0 = 0`: колесо в повітрі не дає моменту другому без гальмування [Т]. Модель: `T_f = k|T_к|`, `k = (TBR − 1)/(TBR + 1)`.
- **Quaife ATB**: TBR не публікує, оцінки спільноти 2–4:1 [В].
- **В'язкісна муфта** [В] https://en.wikipedia.org/wiki/Viscous_coupling_unit: пластини з отворами, силікон, заповнення близько 80%; момент залежить від різниці швидкостей; нагрів підіймає тиск і момент («горб»). Модель на щілину `T = π η Δω (r_з⁴ − r_в⁴)/(2h)` плюс повільна теплова змінна [Т].
- **Активні**: Honda ATTS (1996), SH-AWD; термін torque vectoring від Ricardo (SAE 2006-01-0818) [В] https://en.wikipedia.org/wiki/Torque_vectoring. Перенести момент можна лише від швидшого боку до повільнішого, якщо немає ступеня з підвищенням, тому потрібна суперпозиційна передача [Т].
- **Реальні:** Civic Type R — гвинтовий передній самоблок [П]; WRX STI — гвинтовий передній, Torsen задній, DCCD [В]; Porsche 992 GTS — PTV Plus з електронним блокуванням [П].

### 15.3 Тертя: модель Карнопа

- Опис Карнопа (ASME J. Dyn. Sys. Meas. Control 107:100–103, 1985) у дисертації Ольссона, §2.4 [П] https://lup.lub.lu.se/search/files/4768278/8840259.pdf: інтервал нульової швидкості `|v| < DV`; усередині тертя — обмежена зовнішня сила, ззовні — статична функція швидкості; «інтервал може бути досить грубим і все одно давати прилипання-ковзання»; вада — модель залежить від решти системи.

Siemens: осцилятор тертя, нестійкий там, де крива тертя має від'ємний нахил [П] https://www.plm.automation.siemens.com/media/global/it/Siemens-SW-Avoiding-judder-in-automatic-transmissions_White%20Paper_tcm56-84214.pdf. Смуга 5–20 Гц [Н]. Модель: `μ(Δω) = μ_k + (μ_s − μ_k)e^{−|Δω|/ω_s}`.
- **Енергія рушання [О]:** при сталих обертах двигуна зчеплення розсіює рівно кінетичну енергію, передану авто, плюс роботу опору під час ковзання. Авто KAIST у 1-й, 2000 об/хв: синхронна швидкість 4,30 м/с, щонайменше 14,8 кДж за рушання. Перемикання 1→2 у DCT KAIST — 1,74–2,22 кДж.

Для них порядок такий: рядок EPA, якщо є (Supra, Prius); інакше брошурні `Cd·A` на одну глобальну поправку `k_EPA = середнє C_EPA/(½ρ·Cd·A)` на авто, що мають і рядок EPA, і брошурні Cd та A. Поправка має бути більшою за 1, бо вибіг EPA містить ще й квадратичні втрати шин; якщо вона виходить за 1,0–1,4, треба шукати причину.
- **Вибіг EPA на нейтралі [Т].** Коефіцієнти `A, B` уже містять тертя головної передачі й підшипників коліс. Для авто з рядком EPA модель не додає холостих втрат головної передачі, інакше опір рахується двічі.
- **Mercedes:** 0,001 Cd ≈ 10 кг маси у WLTP [П] https://media.mercedes-benz.fr/download/a3710190-135f-4412-9cd3-7fd11375063d/pm_aerodynamics_en.pdf.
- **Опір кочення (етикетка шин ЄС)** [П] https://legislation.gov.uk/eur/2020/740/annex/I/part/1: клас A ≤ 6,5 Н/кН, B 6,6–7,7, C 7,8–9,0. За замовчуванням 0,008–0,010 для звичайних шин, 0,011–0,013 для спортивних [Н].
- **Радіус кочення:** `D = обід·25,4 + 2·ширина·профіль`; `r_дин ≈ 0,97·D/2` [Н]; 205/55 R16 має динамічне коло близько 1,94 м проти 1,98 м статичного [В].
- **Шина вздовж** (з дослідження підвісок, `suspensions-dynamics-data.md` §7) [П, Chalmers і файли .tir]: поздовжня жорсткість ковзання `C_κ/F_z ≈ 18–34`, пік `μ_x` при `κ ≈ 0,06–0,14`, виміряна 25–50 кН на одиницю ковзання; щітка: `F = Cs − (Cs)²/(3μF_z) + (Cs)³/(27(μF_z)²)` до повного ковзання; довжина релаксації поздовжня близько 0,23 м.
- **Мала швидкість [О]:** звичайне ковзання `κ = (ωr − v)/|v|` дає сталу часу колеса `τ = J_w v/(C_κ r²)`: 0,06 мс на 0,5 м/с, 0,34 мс на 3 м/с, 3,4 мс на 30 м/с. Нижче близько 3 м/с явний крок 1/3000 с нестійкий, а саме там живе рушання. Вихід — модель з деформацією протектора як станом (Clover і Bernard, «Longitudinal tire dynamics», *Vehicle System Dynamics*, 1998 [Н, знайдено лише анотацію]): вона скінченна при `v = 0`, і шина стає крутильною пружиною близько 31 кН·м/рад на колесі, мода близько 30 Гц, стійка на 3 кГц і на 5 мс [О].

Планетарний ряд: `f = z_s|n_s − n_c|/60 = z_r|n_r − n_c|/60` [О].
- **Рівень** (NASA) [П] https://ntrs.nasa.gov/api/citations/19940029466/downloads/19940029466.pdf, https://ntrs.nasa.gov/api/citations/19940029448/downloads/19940029448.pdf: найважливіше — сумарний коефіцієнт перекриття. - **Закон для синтезу [О].** Один показник `ε_γ^(−0,6)`, підібраний на прямозубих (2 дБ між `ε_α` 1,43 і 2,1), дає косозубим лише близько 4 дБ замість 9–17. Тому осьове перекриття має окремий член: `c = (ε_α/1,43)^(−0,6)·(1 + (2,5·ε_β)²)^(−1/2)`. Підбір дає 2,25, 2,73 і 2,46 для трьох косозубих, узято 2,5. Закон повторює рівні: −10,3 дБ (виміряно близько −9), −13,2 (−14), −17,1 (−17). Фізичний зміст: контактні лінії косого зуба усереднюють коливання жорсткості зачеплення по ширині, а похибки напрямку зуба не дають цьому усередненню дійти до нуля.
- **Психоакустика** (RWTH WZL, Brecher та ін., *Gear Technology* 08/2011) [П] https://ik.imagekit.io/agmamedia/gt/issues/0811x/brecher.pdf: шум шестерень оцінюють за тональністю, шорсткістю й різкістю, а не лише за дБ; шорсткість від модуляції 20–300 Гц; слух найчутливіший близько 2–4 кГц. Отже, бічні смуги з частотою вала роблять завивання шорстким майже в усьому діапазоні [Т].
- **Маскування** (SMT, *Gear Technology* 03/2019) [П] https://ik.imagekit.io/agmamedia/gt/issues/0319x/gear-whine.pdf: в електромобілі порядки шестерень біля вуха водія сягають близько 37 дБА, різниця між загальним шумом і порядками шестерень понад 20 дБА; ДВЗ маскує порядки шестерень.
- **Висновки [Т]:** завивають переважно навантажені зачеплення; пряма передача тиха, бо зачеплення не навантажені; прямозубий задній хід і гоночні шестерні завивають сильно; бокові поверхні тяги й гальмування мають різну мікрогеометрію, тож тон змінюється при скиданні газу.

### 18.2 Деренчання

- Механізм (LuK 1994) [П]: ненавантажені шестерні б'ються в зазорі від нерівномірності обертання двигуна, збудження 20–400 Гц. Демпфер у диску лишає моду коробки 40–80 Гц у смузі збудження; двомасовий маховик зсуває її до 7,5–15 Гц і прибирає 93–95% нерівномірності.
- Виміряна смуга ударів 450–4000 Гц; найкраще з неприємністю корелює Articulation Index, r = 0,948 [П, анотація] https://saemobilus.sae.org/articles/vibro-impact-analysis-manual-transmission-gear-rattle-sound-quality-evaluation-2017-01-0403.
- **Поріг [О/Т]:** вільна шестерня відривається від бокової поверхні, коли `J_ш|α| > T_оп`. Приклад: ±1° на 26,7 Гц (чотирициліндровий на 800 об/хв) дає `|α| ≈ 490 рад/с²`; з `J_ш ≈ 10⁻³ кг·м²` [Н] це 0,49 Н·м, більше за типовий опір, тож деренчить; після 93% зниження двомасовим маховиком 0,03 Н·м, тож тихо.
